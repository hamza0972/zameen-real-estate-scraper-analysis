# 🏠 Zameen.com Real Estate Scraper & Analysis

A Python-based data science project that scrapes property listings from **Zameen.com**, cleans and transforms the collected data, and performs exploratory data analysis (EDA) on real estate listings from **Faisalabad, Lahore, and Islamabad**.

The project demonstrates an end-to-end workflow:

**Web Scraping → Data Cleaning → Feature Engineering → Exploratory Data Analysis**

---

## 📌 Project Overview

This project was created to practice practical **Python web scraping, data cleaning, feature engineering, Pandas, NumPy, and data visualization** skills using real estate listing data.

Property listings were collected from Zameen.com for:

- Faisalabad
- Lahore
- Islamabad

The scraped data includes information such as:

- Property price
- Area
- Bedrooms
- Bathrooms
- Location
- City

The raw data was then cleaned and transformed into a structured dataset suitable for analysis.

---

## 🎯 Objectives

The main objectives of this project are to:

- Practice web scraping with Python
- Collect real-world property listing data
- Clean and preprocess messy scraped data
- Handle missing values and duplicate records
- Convert property areas into Marla and square feet
- Convert property prices into numeric PKR values
- Calculate price per Marla
- Perform exploratory data analysis
- Compare real estate characteristics across cities
- Visualize patterns and relationships in the dataset
